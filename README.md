# MiggyOS
MiggyOS is the OS to control and duplicate Miggys on your Miggy system controller. Every Miggy is controlled by the MiggyOS which is a method of controlling Miggys. Computer are obsolete.

Future developments to MiggyOS will occur at github.com/MiggyOS. I am still learning the tools and theory, so there might not be much on it for the next month or so.
